# Chickpea Chicken Salad

## Ingredients

### Base

Both recipes below use these common ingredients.

| Serving | Ingredient | Notes |
|-|-|-|
| 1 can | Chickpeas | Drained and rinsed |
| 1/2 cup | Greek yogurt |  |
| 1 tbsp | Lemon juice | Or 1 whole lemon's worth of juice |
| 2 cups | Grapes | Sliced in half |
| 1/2 tsp | Salt |  |
| 1/2 tsp | Pepper |  |
| 6-8 | Croissants |  |
| 1 head | Lettuce |  |

#### Option A

| Serving | Ingredient | Notes |
|-|-|-|
| 1/2 tbsp | Dijon mustard | Can substitute 1/2 tsp mustard powder |
| 1/2 tsp | Poultry seasoning |  |
| 2 tsp | Dill |  |
| 1/3 cup | Slivered almonds |  |

#### Option B

| Serving | Ingredient | Notes |
|-|-|-|
| 1/2 cup | Sour cream |  |
| 1 tbsp | Dill |  |
| 1 cup | Pecans | Sliced and toasted in a pan over medium heat for a few minutes |

## Instructions

1. Prepare all ingredients (Option B requires some cooking ahead of time).
1. Dump chickpeas into a large glass bowl and mash about 50-75% of the way.
1. Add all other ingredients and mix well.
1. Serve on a croissant with lettuce.
